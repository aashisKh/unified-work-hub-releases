# Unified Work Hub - downloads

This repository only holds the installers for **Unified Work Hub**, so the app can download updates.
There is no source code here.

- **Windows:** `Unified Work Hub Setup <version>.exe`
- **Mac (Intel and Apple Silicon):** `Unified Work Hub-<version>-mac-universal.dmg`

Get the latest from the [Releases](../../releases/latest) page. Only install a copy that came from the
WorkHub team or from this page.

The apps are not code-signed yet, so Windows ("Windows protected your PC") and macOS ("Apple could not verify...")
show a warning the first time. The step-by-step instructions are in the HOW-TO-USE file that comes with the installer.
